# SMART HOME AI PRO

نسخة أولية عملية ومتجاوبة للويب وAndroid عبر PWA.

## التشغيل
1. فك ضغط الملف.
2. افتح مجلد المشروع في محرر أو ارفع محتوياته إلى استضافة تدعم HTTPS.
3. افتح `index.html` للمعاينة المحلية. بعض ميزات PWA (التثبيت والعمل دون اتصال) تتطلب استضافة HTTPS أو localhost.
4. على Android افتح رابط الموقع في Chrome ثم اختر «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».

## الموجود حالياً
- لوحة تحكم، معاملات دخل ومصروف، ميزانية شهرية، رسوم مبسطة وتقارير.
- تخزين محلي في المتصفح وتصدير CSV.
- مساعد تجريبي يحلل البيانات المسجلة محلياً، مع إدخال صوتي إذا كان المتصفح يدعمه.
- واجهة عربية RTL وتصميم داكن متجاوب.

## ملاحظات مهمة
- هذا إصدار MVP أولي وليس تطبيقاً منشوراً في Google Play.
- المساعد الحالي ليس نموذج ذكاء اصطناعي سحابياً ولا يقدم تشخيصاً لمشاكل الأجهزة المنزلية؛ ربط AI حقيقي يتطلب Backend آمن ومفتاح API محفوظاً على الخادم، وليس داخل التطبيق.
- البيانات محلية على الجهاز؛ لا توجد مزامنة بين أجهزة أو حسابات مستخدمين بعد.
- لا تدخل بيانات مالية حساسة قبل إضافة المصادقة والنسخ الاحتياطي والتشفير ومراجعة الأمان.
